# Phase 4: ループ — 続けるか決める

```bash
node kiai-sp/lib/spec-testing/check-progress.mjs --dir <artifact_dir> --phase execution
```

| 終了コード | 意味 | やること |
|---|---|---|
| `0` | `todo` が 0 件。完了 | Phase 5 へ |
| `1` | まだ残っている | Phase 1 に戻る |
| `2` | 検査できなかった | **エラーで停止する** |

`fail` が残っていても `0` で終わる。FAIL の修正はこのスキル群のスコープ外である。

## 主観で終わらせない

「一通り確認できた」「これ以上やっても同じだ」は終了条件ではない。判定は検査
スクリプトの終了コードだけである。親の裁量を入れない。

## 前進の確認

`progress.json` の `advanced_this_turn` が 0 のまま続くなら、消化が進んでいない。
ゲート側がこれを見て自主停止する。ここでは何もしない。
