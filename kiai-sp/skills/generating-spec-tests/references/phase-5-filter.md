# Phase 5: Filter — 閾値で足切り

```bash
node <skill_dir>/lib/score.mjs --workdir <workdir> --attempt <N>
```

`<N>` は今回が何回目の採点かを表す。1 から始める。

| 終了コード | 意味 | やること |
|---|---|---|
| `0` | 全件採点できた | Phase 6 へ進む |
| `3` | 未採点がある。上限内 | Phase 4.3 に戻り、`--attempt` を 1 増やして再実行する |
| `2` | 検査できなかった | **エラーで停止する** |

3 回試しても採点できなければ止まる。**中間値で埋めない。**

このパイプラインは取りこぼしが次周回で回復しない。テスト計画は 1 回しか作られず、
落ちた指摘は次に拾われない。中間値で埋めると閾値で自動的に落ちるため、採点系の
バグが「指摘が少なかっただけ」に見えて永久に気づけない。

停止するときは、何が採点できなかったかを標準エラーの内容ごとユーザーに伝える。
