一つ前のAIの発話を、四角いっぱい、絵文字いっぱいのアスキーアートで説明せよ。ぜんぜんユーザーはAIの発言内容を理解していない。
この発話ルールは、スキルを起動した直後の返事にだけ使う。それ以外の返事では、このルールを忘れて、普通の書き方に戻す。

## 必ず守ること

- 図は必ずスクリプトに組ませる。罫線を自分で打たない。出てきた文字をそのまま貼る
- 3 段の順番を守る。下書きを飛ばして、いきなり JSON を書き始めない
- スクリプトが止まったら、エラーの文言に従って JSON を直して走らせ直す。図を自分で描き直して済ませない
- 部品の形は、この文書に書いてあるとおりに書く。形を間違えるとスクリプトが止まる

## 図の作り方

3 段で作る。段を入れ替えない。段を飛ばさない。
下書きと JSON は途中の作業であり、人に見せるのは 3 の結果だけである。見せないのは、下書きが要らないという意味ではない。1 と 2 は必ず通る。

1. **必ずフリーハンドの下書きから始める。飛ばしていきなり JSON を書き始めない。** 構図はここで決める。JSON は、決めた構図を部品に割り当てるだけの手順である。「レイアウトがごちゃごちゃした AA で説明して」と自分に言って、罫線も位置も気にせず、書き込める一時ファイルに txt で描く。ここでは数を数えない。構図だけを決める
2. **JSON に直す。** 下書きの構図を、下の部品に割り当てる
3. **スクリプトを走らせる。** `node <PLUGIN_DIR>/lib/box.mjs <書いたファイル>` に渡し、出てきた文字をそのまま貼る

`<PLUGIN_DIR>` は、このスキルの 2 つ上のディレクトリである。
JSON（と下書きの txt）の置き場所は、書き込める一時ファイルに置く。リポジトリの追跡対象には書かない。

## 部品

ブロックを `{"blocks": [...]}` に並べる。`box` `row` `stack` `tree` `loop` の中には、またブロックを入れられる。

| キー    | 意味                                                                                        |
| ------- | ------------------------------------------------------------------------------------------- |
| `lines` | そのまま出す行。`["1 行目", "2 行目"]`                                                      |
| `bar`   | 見出しの帯。上の線と角も太い線で組む。図の外側で使う                                        |
| `box`   | 枠で囲む。中にブロックを入れる                                                              |
| `row`   | 横に並べる。中にブロックを入れる。`"gap"` で間隔を文字数で決める。省くと 3 文字             |
| `stack` | 枠を付けずに束ねる。中にブロックを入れる。空行は入らない                                    |
| `rule`  | 幅いっぱいの横線。`box` の中だけで使える                                                    |
| `table` | 表。`{"head": ["見出し", ...], "rows": [["セル", ...], ...]}`                               |
| `tree`  | 木。`{"label": "親", "above": [...], "below": [...]}`。`"style"` で見た目を選ぶ             |
| `loop`  | 囲んだまとまりの下に戻り線を引く。`{"loop": {"blocks": [...], "back": 2, "label": "戻る"}}` |

部品の形は、部品ごとにこのとおりである。ここから外れるとスクリプトが止まる。

- `bar` は文字を 1 つ書く。`{"bar": "見出し"}` の形である
- 木の枝は、`"above"` か `"below"` か `"children"` のどれに入れても、`{"label": "子"}` の形のオブジェクトである。文字をそのまま並べると、スクリプトが止まる
- `"style"` は、`tree` の中でなく、`tree` と同じブロックに書く（`{"tree": {...}, "style": "box"}`）

`tree` の見た目は 2 つ。`"style": "indent"` は字下げ、`"style": "box"` は箱つきである。`"style"` は省けない。`"indent"` か `"box"` のどちらかを必ず書く。どちらでもないとスクリプトが止まる。

箱つきの木では、1 つの箱から上にも下にも枝を出せる。`"above"` が上の枝、`"below"` が下の枝である。`"children"` は `"below"` と同じ意味で、下の枝しか無いときに使う。これで、多 → 1 → 多 の形が 1 つの塊で書ける。`"above"` は `"style": "indent"` では使えない。

`row` に並べた部品は、縦の真ん中にそろう。真ん中の基準は、並んだ中でいちばん背の高い部品である。こうしておくと、箱のあいだに置いた矢印が、どの箱でも枠線ではなく中身の行に当たる。
上にそろえたい部品があれば、その部品に `"align": "top"` を書く（`{"box": [...], "align": "top"}`）。`row` の側に書くと、スクリプトが止まる。`"align"` に書ける値は `"top"` と `"middle"` だけで、ほかの値ではスクリプトが止まる。

`loop` は、囲んだブロックを横に並べ、間を矢印でつなぐ。そのうえで、下に戻り線を 1 本引く。`"back"` は、何番目のブロックへ戻すかである。1 から数える。戻り線で書けるのは、横に並んだまとまりの下を戻る形だけである。

`blocks` の直下は、ブロックとブロックの間が空行で区切って出る。`stack` の中は区切られない。

箱の中に見出しを置きたいときは、`bar` ではなく `rule` と `lines` を使う。`bar` はそれ自体が枠なので、箱の中に入れると枠が二重になる。

## 罫線の種類

ブロックごとに `"line"` で選ぶ。文書全体では `{"line": "light", "blocks": [...]}` と書く。省くと `light` になる。ただし `--mode=strict` のときは `ascii` になる。

| 名前     | 見た目                   |
| -------- | ------------------------ |
| `ascii`  | ASCII の記号。枝は `+--` |
| `light`  | `┌` `─` `│` `├` `└`      |
| `heavy`  | `┏` `━` `┃` `┣` `┗`      |
| `double` | `╔` `═` `║` `╠` `╚`      |

## 使ってよい字

端末によって幅が変わる字を書くと、スクリプトが止まって、その字を全部挙げる。
挙げられた字を書き直してから、もう一度走らせる。図を自分で描き直して済ませない。

端末まかせの字:

- 異体字セレクタ付きの記号と絵文字：`⚠️` `🌬️` `❄️` `♨️` `🌡️` `1️⃣`

これらは、端末が 1 桁と見るか 2 桁と見るかを数える手立てが無い。どちらのモードでも弾かれる。

矢印:

- 既定では `←` `→` `↑` `↓` を使う
- `--mode=strict` で走らせるときは `->` を使う

## モード

| モード                     | 挙動                                                               |
| -------------------------- | ------------------------------------------------------------------ |
| 既定（`--mode=ambiguous`） | 曖昧幅の字を幅 1 として通す。罫線に `┌ ─ │`、矢印に `← →` が使える |
| `--mode=strict`            | 曖昧幅の字を弾く。罫線は `ascii` に落ちる。矢印は `->`             |

`loop` の戻り線の先の印は、`ambiguous` では `↑`、`strict` では `^` である。

どちらのモードでも、幅の計算はスクリプトがやる。自分で数えない。

人間が「端末によって崩れるのは困る」と言ったら、`--mode=strict` で走らせる。
