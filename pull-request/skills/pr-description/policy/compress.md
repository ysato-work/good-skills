# 圧縮方針

PR 説明文と行コメントを短くする。人間が読む文章なので、トークンを使ってでも短くする価値がある。

## 消していいもの

- 冗長な修飾
- 同じことの言い直し
- 差分を見れば分かる記述
- 前置き。「まず」「今回は」
- なんでこれを書こうと思ったか意味が汲み取れないもの

## 残すもの

- 固有名詞、数値、ファイルパス、行番号
- 番号コメントの番号
- 「なぜ」の因果関係
- 検討して捨てた選択肢

「固有名詞を残す」は、日常語に言い換えた語を識別子に戻す許可ではない。短くするために変数名・関数名・型名へ戻すのは禁止。

## 変えてはいけないもの

- 日常語に言い換えた語。識別子に戻さない
- 主眼の文の意味
- 予約タイトルの summary 文字列 `概要` / `変更のサマリー` / `ドキュメント` / `テスト`
- 番号の順序
- HTML コメントのマーカー行（`<!-- pr-desc: ... -->`）
- 丸括弧で補足を足さない。短くするために丸括弧へ戻すのは禁止
